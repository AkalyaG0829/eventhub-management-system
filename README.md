# EventHub — Event & Hackathon Management Platform

## Overview
EventHub is a comprehensive full-stack application for managing and participating in events and hackathons. It provides dedicated features for Participants, Organizers, and Admins.

## Features
- **Participants:** Browse events, register, form teams, and submit hackathon projects.
- **Organizers:** Create events, manage registrations, review submissions, and publish leaderboards.
- **Admins:** Oversee users, events, and platform statistics.

## Technology Stack
- **Backend:** Java 17, Spring Boot 3.x, Spring Security (JWT), Spring Data JPA
- **Database:** MySQL
- **Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Lucide React

## Folder Structure
- `backend/`: Spring Boot Application
- `frontend/`: React Vite Application
- `docs/`: Additional documentation
